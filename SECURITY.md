# Security policy

## Supported versions

AI Product Studio is currently pre-1.0. Security fixes are applied to the latest
version on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
private GitHub security advisory reporting feature and include:

- Affected version or commit.
- Reproduction steps.
- Expected and observed behavior.
- Potential impact.
- Suggested mitigation, if known.

Do not include credentials, private product files, or customer data in a report.
